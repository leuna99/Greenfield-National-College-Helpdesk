Unit 1 — Introduction to Computer System

Introduction to computers, characteristics, applications, classification, basic computer organization, memory, input and output devices.

Unit 2 — Computer Software

Software concepts, system software, application software, programming languages and computer programs.

Unit 3 — Operating System

Operating system concepts, functions, types and basic operating-system services.

Unit 4 — Database Management System

Database concepts, database models, DBMS, SQL, database design and database security.

Unit 5 — Data Communication and Computer Network

Data communication, computer networks, network types, topologies, transmission media, network devices and protocols.
